## 📦 5. Cara Membuat File ZIP untuk Didistribusikan ke Pembeli

Sebelum meng-upload file ZIP ke Gumroad, pastikan folder bersih dari file sampah (`node_modules`, `.svelte-kit`, `.env` yang berisi rahasia asli):

1. Hapus folder `node_modules` dan `.svelte-kit` jika ada di zip.
2. Pastikan file `.env.example`, `schema.sql`, `SETUP_GUIDE.md`, dan `README.md` ada di dalam root folder.
3. Compress seluruh folder project menjadi `padel-club-template-v1.0.0.zip`.
4. Upload `padel-club-template-v1.0.0.zip` ke Gumroad pada bagian **Content / Files**.
